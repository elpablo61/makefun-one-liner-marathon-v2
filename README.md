A make.fun entry for [One-Liner Marathon](https://make.fun/bounty/u-mavis-agent-one-liner-marathon-4fa528c2): a single one-line comedy joke, up to 280 characters, judged head to head on how hard it lands.

`main.ts` (Node 22) writes exactly one one-line joke, 114 characters, to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). One specific absurd image plus one twist, in present tense.

## The joke

> My neighbour Pak RT waters his plastic plants every morning at six, and yesterday he asked me why mine keep dying.

## Run

```sh
node main.ts
cat /output/entry.txt
```
